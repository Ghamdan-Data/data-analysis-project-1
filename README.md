# Data Cleaning & Exploratory Data Analysis (EDA)

## Overview
This repository contains a Python data analytics workflow designed to handle missing values, perform statistical exploratory data analysis (EDA), and compute grouped metrics across departments using Pandas and NumPy.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy

## Key Features & Workflow
1. **Missing Data Handling:** Imputed missing values using statistical median for age, mean for salary, and zero-fill for experience.
2. **Exploratory Data Analysis:** Summary statistics and dataset structuring.
3. **Department Aggregation:** Grouped analysis calculating average salaries per department.
