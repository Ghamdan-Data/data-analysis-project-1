# Data Cleaning & Exploratory Data Analysis (EDA)

## Overview
This repository contains a Python project focused on data cleaning and exploratory data analysis (EDA). The project demonstrates fundamental data preprocessing steps, including handling missing values and extracting structural dataset information.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy

## Project Features
* Data cleaning and null value identification.
* Dataset structure exploration (`info()`, statistical overview).
* Structuring clean data for analytical pipelines.
